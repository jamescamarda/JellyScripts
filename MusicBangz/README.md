# MusicBangz

Search Discogs release and track metadata on YouTube, Spotify, Qobuz, Bandcamp, Apple Music, Google, Yandex, or Last.fm.

Install [MusicBangz.user.js](MusicBangz.user.js) in Violentmonkey.

Enable **Tab lock** in the extension menu to reuse a script-opened search tab. Closing that tab releases the lock; turning the option off opens each search in its own new tab.
