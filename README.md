# JellyScripts

A small collection of music utilities and Violentmonkey userscripts.

## Scripts

- [CUE Audio](CueAudio/README.md) — split CUE images, match existing tracks, tag and rename audio.
- [MusicBrainz Loved enrichment](MusicBrainzLibrary/README.md) — a resumable Violentmonkey coordinator using String Theory to verify editions, import digital releases and fill recording stream links; no remote debugging required.
- [YandexTabLock](YandexTabLock/README.md) — keep normal Yandex result clicks in the current tab.
- [Release streams to MusicBrainz recordings](LinkRecordingLevel/README.md) — select Spotify, YouTube and SoundCloud links on a release, collect them together, and review combined recording edits.

Install the [Violentmonkey](https://violentmonkey.github.io/) browser extension, then open a script file from this repository to install it.
